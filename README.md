# 陈迪 · Di Chen

A bilingual, responsive academic homepage built with plain HTML, CSS, and JavaScript. No build step or external services are needed.

## Preview

Run `python -m http.server 8765 --bind 127.0.0.1` in this directory, then visit http://127.0.0.1:8765.

## GitHub Pages

1. Create a public repository named `dichen578-oss.github.io` in your GitHub account.
2. Upload `index.html`, `style.css`, `script.js`, `.nojekyll`, and the `assets` directory to its main branch.
3. In Settings → Pages, choose Deploy from a branch → main → / (root).
4. Once GitHub reports successful deployment, visit `https://dichen578-oss.github.io/`.

The intended public URL is https://dichen578-oss.github.io/. Publication requires GitHub authorization and a successful Pages deployment.

## Content

Edit the Chinese and English `data-zh` / `data-en` attributes together in `index.html`. The photograph is displayed with CSS framing; the original image remains in the assets folder. Graduate institution, program, and university email are included with permission. Publications and unpublished research details are omitted.
